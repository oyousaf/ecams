# ECAMS

Website for ECAMS, an eco-friendly cleaning and maintenance company in London.

## Tech stack

- [Next.js 16](https://nextjs.org) (App Router, React 19, Server Actions)
- [TypeScript 5](https://www.typescriptlang.org)
- [Tailwind CSS 4](https://tailwindcss.com)
- [Motion 14](https://motion.dev)
- [Resend](https://resend.com) and [Zod 4](https://zod.dev) for the quote form
- [Lucide](https://lucide.dev) icons
- Bricolage Grotesque and Geist fonts
- Hosted on [Vercel](https://vercel.com)

## Features

- Eco-focused design with a forest, lime and off-white palette
- Light and dark themes that follow the device setting, with an Auto / Light / Dark switch
- Service overview plus a page for each category: domestic, specialist, garden and vehicle
- Full price list, with a tabbed price explorer on the home page
- Quote and booking request form with validation, spam protection and the chosen service pre-filled
- Sticky Call / Quote bar on mobile and a scroll-to-top button with a progress ring
- Scroll-triggered animations that respect reduced-motion settings
- Local business structured data, sitemap and robots rules
- Redirects from the old site's URLs
- Accessible: skip link, keyboard focus styles, labelled controls and semantic headings
